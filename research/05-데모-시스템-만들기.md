# 데모 시스템 만들기

## 목적
잠재 고객이 제품 가치를 빠르게 이해할 수 있도록 실제 사용 흐름을 보여주는 시연 환경을 만드는 단계다.

## 세부 할 일
- 영업용 데모 계정 구성
- 관리자 데모 시나리오 구성
- 수강생 데모 시나리오 구성
- AI 기능 데모 장면 구성
- DRM/보안 기능 데모 시나리오 구성
- 계정공유 탐지 데모 구성
- 데모용 샘플 강의 업로드
- 고객 유형별 데모 흐름 작성
- 5분 버전 데모 작성
- 15분 버전 데모 작성
- 자주 발생하는 질문 대응 문구 준비

## 결과물
- 데모 계정
- 시연 스크립트
- 짧은 데모/긴 데모 버전
