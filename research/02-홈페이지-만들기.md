# 홈페이지 만들기

## 목적
홈페이지는 회사와 서비스를 신뢰하게 만들고, 문의와 데모 신청을 받는 핵심 채널이다.

## 세부 할 일
- 메인 카피 작성
- 서비스 소개 페이지 구성
- 기능 소개 페이지 구성
- AI 기능 소개 페이지 구성
- 보안/DRM 소개 페이지 구성
- 고객 사례/활용 예시 페이지 구성
- 데모 신청 페이지 구성
- 문의 페이지 구성
- FAQ 페이지 구성
- 회사 소개 페이지 구성
- 가격 문의 구조 설계
- CTA 문구 정리
- 폼 수집 항목 설계
- SEO 기본 세팅
- GA/전환 추적 설치
- 모바일 최적화
- 속도 최적화

## 결과물
- 기본 회사 홈페이지
- 데모 신청 랜딩 페이지
- 기능/보안/사례 소개 페이지
