# 브로셔 만들기

## 목적
브로셔는 처음 보는 잠재 고객에게 우리 서비스가 무엇인지, 왜 필요한지, 무엇이 다른지를 짧은 시간 안에 이해시키는 기본 영업 자료다.

## 세부 할 일
- 서비스 한 줄 정의 정리
- 핵심 기능 5~7개 정리
- 고객이 얻는 효과 정리
- 기존 LMS 대비 차별점 정리
- AI 기능 설명 정리
- DRM/보안 기능 설명 정리
- 계정 공유 탐지 기능 설명 정리
- 대상 고객군별 메시지 분리
- 2페이지 버전 제작
- 4페이지 버전 제작
- 제안형 브로셔 버전 제작
- PDF 브로셔 디자인
- 인쇄용 버전 제작
- 영업용 요약본 제작

## 결과물
- 영업용 PDF 브로셔
- 인쇄용 브로셔
- 고객 유형별 요약 버전
