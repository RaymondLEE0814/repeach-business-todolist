# 06. 입학 요건 및 선발 체계

## 목적
누가 프로그램에 들어올 수 있는지, 어떤 학생을 어떤 기준으로 선발할지를 정하는 단계다.

## 세부 할 일
- 한국 고교 내신 반영 방식 조사
- GCSE/A-Level 요구 여부 조사
- IELTS/UKVI English 조건 조사
- 의대 준비생의 추가 시험 요구 여부 조사
- 약대 입학 요구 조건 조사
- 과학 과목 선수학습 기준 정리
- 인터뷰 필요 여부 검토
- 내부 레벨 테스트 설계 여부 결정
- 의대트랙/약대트랙 진입 기준 분리
- 조건부 입학 구조 설계
- 탈락/유보 기준 설계
- 사전 상담 체크리스트 제작 항목 정리
- 학생 적합도 판별 질문지 초안 정리

## 결과물
- 지원 자격 기준표
- 내부 선발 기준안
- 상담용 적합도 체크리스트
