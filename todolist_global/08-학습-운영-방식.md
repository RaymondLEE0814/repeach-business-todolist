# 08. 학습 운영 방식

## 목적
프로그램을 실제로 어떤 형태로 운영할지 실행 구조를 정하는 단계다.

## 세부 할 일
- 온라인 라이브 수업 여부 결정
- 녹화 수업 활용 구조 결정
- 오프라인 수업 여부 검토
- 한국 내 학원형 운영 가능성 검토
- 영국 현지 캠프형 운영 가능성 검토
- 혼합형 운영 시 시간표 구조 설계
- 1:1 튜터링 포함 여부 결정
- TA/멘토 배치 여부 검토
- 출결 관리 방식 설계
- 과제 제출 방식 설계
- 테스트 운영 방식 설계
- LMS 필요 기능 정리
- 부모 리포트 제공 여부 검토
- 학습경고 시스템 필요 여부 검토
- 학사 운영 캘린더 설계

## 결과물
- 운영 방식 문서
- 학사 캘린더 초안
- LMS/운영 요구사항 문서
