## 배경 / 목표
PRD의 핵심 기능 **"오늘 / 이번 주 실행 화면"**:
> 흩어진 할 일을 오늘 할 일로 모아 실행에 집중하게 합니다.

여러 프로젝트에 흩어진 할 일을, **마감/계획일 기준**으로 한 화면에 모아
"지금 뭘 해야 하는지"에 집중하게 한다. 워크스페이스(프로젝트별 보기)와 별개의
**상단 모드 전환**으로 제공한다.

## 사용자 시나리오
- 로그인 → 대시보드 상단에서 **「오늘 · 이번 주」** 탭 선택
- 모든 프로젝트의 할 일이 날짜 기준으로 묶여 보인다: 지남 / 오늘 / 이번 주 / 이후 / 날짜 없음
- 각 할 일에는 소속 프로젝트·난이도 뱃지가 함께 표시된다
- 체크하면 목록에서 사라지고(실행 집중) XP·컨페티 보상

## 데이터 변경
```sql
alter table public.todos add column if not exists due_date date;
```
- RLS는 기존 owner 규칙을 그대로 따른다(컬럼 추가뿐).

## 설계 결정 / 이슈
1. **날짜 모델**: 별도 "오늘 담기" 플래그 대신 **계획일(due_date)** 사용.
   → 같은 날짜 필드로 "오늘/이번 주/이후"를 모두 표현, 캘린더 연동(예정)과도 호환.
2. **이번 주 정의**: 오늘 다음날 ~ 이번 주 일요일(달력 주). 일요일이면 비어 있을 수 있음(허용).
3. **프로젝트명 매핑**: projects↔todos에 FK가 없어 PostgREST 임베드 불가
   → todos/projects를 각각 조회해 `project_id→name` 클라이언트 매핑.
4. **완료 항목 처리**: 실행 집중을 위해 버킷에서는 **미완료만** 표시(체크 시 사라짐).
5. **마이그레이션 순서**: due_date 컬럼은 추가/편집 insert·update에서 쓰이므로
   **마이그레이션을 먼저 실행한 뒤 배포**. 읽기는 컬럼 없을 때 폴백 처리.

## 알려진 한계 / 다음 단계
- 시간(HH:MM) 없이 날짜 단위만 — 시간대/리마인더는 추후.
- 정렬: 버킷 내 날짜 오름차순. 우선순위/드래그 정렬은 추후.
- 성취 로그·주간 리포트(개정안 잔여)와 연계 시 `cleared_at` 활용 예정.
