# Mindash 게임화(Gamification) 설계 — v1

> 사람들이 자기 프로젝트를 만들고 할 일을 하나씩 완료할 때마다,
> 게임 퀘스트를 깨듯 XP·칭호·시각적 보상을 주어 성취를 시각화한다.
> 구현 위치: [`mindash/lib/gamification.ts`](../../mindash/lib/gamification.ts), [`mindash/app/dashboard/Workspace.tsx`](../../mindash/app/dashboard/Workspace.tsx)

## 핵심 원리
- 보상은 **완료한 할 일 수**(본인 소유 전체)로 계산 — 별도 DB 컬럼 없이 `todos.completed`만 사용.
- 계정별 격리(owner_id + RLS) 위에서 동작하므로 각자 자기 XP를 쌓는다.

## ① XP & 레벨
- 할 일 1개 완료 = **+10 XP**
- 레벨 구간:

| 레벨 | 누적 XP | 칭호 | 아이콘 |
|---|---:|---|---|
| Lv1 | 0 | 새싹 | 🌱 |
| Lv2 | 50 | 일꾼 | 🔨 |
| Lv3 | 120 | 능력자 | ⚡ |
| Lv4 | 250 | 마스터 | 🎯 |
| Lv5 | 450 | 전설 | 👑 |
| Lv6 | 700 | 그랜드마스터 | 🏆 |

- 대시보드 상단 **게임 바**에 현재 레벨·칭호·다음 레벨까지 남은 XP·진행 바 표시.

## ② 업적(배지)
누적 완료 개수 기반:

| 업적 | 조건 | 아이콘 |
|---|---|---|
| 첫 발걸음 | 1개 완료 | 👣 |
| 탄력 받는 중 | 10개 완료 | 🔥 |
| 꾸준함의 증명 | 50개 완료 | 💎 |
| 백전백승 | 100개 완료 | 🌟 |

추가 즉시 보상(완료 순간 판정):
- **프로젝트 완주** — 프로젝트의 모든 할 일 100% (🏁)
- **구역 정복** — 한 카테고리의 할 일 올클리어 (✅)

## ③ 시각적 보상
- 할 일 체크 → **컨페티 폭발** + XP 바 애니메이션
- 레벨업 / 업적 달성 / 완주 → 상단 **토스트 알림** (칭호·배지 등장)
- 보상 우선순위: 레벨업 > 누적 업적 > 프로젝트 100% > 카테고리 올클리어
